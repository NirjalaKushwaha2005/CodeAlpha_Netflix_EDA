# CodeAlpha_Netflix_EDA
# Netflix Movies and TV Shows – Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset to identify trends, patterns, and insights about Netflix content.

This project was completed as part of the CodeAlpha Data Analytics Internship – Task 2.

## Objectives

* Analyze Movies vs TV Shows distribution.
* Explore Netflix content ratings.
* Identify the top 10 countries contributing content.
* Analyze content release trends.
* Identify missing values and duplicate records.
* Extract meaningful insights from the dataset.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* VS Code
